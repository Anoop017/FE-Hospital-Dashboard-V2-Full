About the Hospital Management System

Frontend

Two separate portals built with Next.js / TypeScript and deployed on Netlify — Admin Portal and Patient/Doctor/Staff Portal.

Backend

NestJS core backend and a Go microservice running on AWS EC2, managed with PM2.

Database

Shared PostgreSQL, MongoDB Atlas, and Redis services.

Infrastructure

Nginx handles reverse proxying and routes requests to the appropriate backend service.

Security

Custom domains with HTTPS/SSL via Let's Encrypt, JWT authentication, and role-based access control.

Real-time & Reports

Go service handles WebSocket-based ICU vitals and PDF report generation.
